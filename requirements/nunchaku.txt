# SVDQuant nunchaku runtime (FLUX / Qwen-Image quantized inference).
# NVIDIA GPUs only, on Linux or Windows. NodeTool does not install it.
#
# Do NOT `pip install nunchaku`: the PyPI package of that name is an unrelated
# project (piece-wise linear segmentation).
#
# nunchaku is a CUDA extension compiled against one torch minor version, so it
# must match the torch in the NodeTool environment (this package requires
# torch 2.14), its CUDA version, and the Python version.
#
# 1. Prebuilt wheel. Releases are at
#    https://github.com/nunchaku-ai/nunchaku/releases and are named
#      nunchaku-<version>+cu<CUDA>torch<MAJOR.MINOR>-cp<PY>-cp<PY>-<platform>.whl
#    Install the one whose torch<MAJOR.MINOR> equals the installed torch, e.g.
#      pip install "https://github.com/nunchaku-ai/nunchaku/releases/download/v<version>/nunchaku-<version>+cu13.0torch2.14-cp311-cp311-linux_x86_64.whl"
#    As of v1.2.1 upstream builds wheels for torch 2.8, 2.9 and 2.10 only, so a
#    torch 2.14 wheel may not exist yet. Do not install a wheel built for a
#    different torch: it fails to load or crashes.
#
# 2. Build from source against the installed torch (needs the CUDA toolkit
#    with nvcc and a C++ compiler):
#      pip install --no-build-isolation "git+https://github.com/nunchaku-ai/nunchaku@v1.2.1"
#
# This file installs nothing by itself; follow one of the steps above.
