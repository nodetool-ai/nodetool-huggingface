# The repository root has no setup.py or pyproject.toml, so `sf3d` itself
# cannot be pip-installed. Install it in two steps, inside the NodeTool Python
# environment:
#
# 1. Install the compiled helpers and runtime dependencies listed below. Their
#    setup.py files import torch, so build them against the installed torch
#    (a C++ compiler is required, and the CUDA toolkit for GPU support):
#      pip install --no-build-isolation -r requirements/sf3d.txt
#
# 2. Clone the source at the pinned commit and put it on the import path with a
#    .pth file:
#      git clone https://github.com/Stability-AI/stable-fast-3d
#      git -C stable-fast-3d checkout ff21fc491b4dc5314bf6734c7c0dabd86b5f5bb2
#      python -c "import pathlib, sys, sysconfig; pathlib.Path(sysconfig.get_paths()['purelib'], 'stable-fast-3d.pth').write_text(str(pathlib.Path(sys.argv[1]).resolve()))" stable-fast-3d
