# This file installs nothing: TRELLIS.2 cannot be installed with
# `pip install -r`. The repository root has no setup.py or pyproject.toml, and
# its CUDA extensions (o-voxel, CuMesh, FlexGEMM, nvdiffrast, nvdiffrec,
# flash-attn) must be compiled against the installed torch. Upstream's
# setup.sh does that. Inside the NodeTool Python environment, with the CUDA
# toolkit (nvcc) and a C++ compiler installed:
#
#   git clone --recursive https://github.com/microsoft/TRELLIS.2
#   cd TRELLIS.2
#   git checkout 5565d240c4a494caaf9ece7a554542b76ffa36d3
#   git submodule update --init --recursive
#   bash setup.sh --basic --flash-attn --nvdiffrast --nvdiffrec --cumesh --o-voxel --flexgemm
#   cd ..
#   python -c "import pathlib, sys, sysconfig; pathlib.Path(sysconfig.get_paths()['purelib'], 'trellis2.pth').write_text(str(pathlib.Path(sys.argv[1]).resolve()))" TRELLIS.2
#
# Do not pass --new-env to setup.sh: it installs torch 2.6, which replaces the
# torch NodeTool needs.
